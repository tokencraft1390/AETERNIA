# AETERNIA

**Two games. One world.**

AETERNIA is the shared world shell for two social games:

- **SIGIL** — Tap. Trust. Betray.
- **ECOSYSTEM** — See alone. Survive together.

## Identity

- Store line: **Aeternia: Social Games on Solana**
- Void: `#0A0A0F`
- SIGIL amber: `#FFB347`
- ECOSYSTEM cyan: `#4FE3C1`

## Phase 0

Phase 0 is evidence-gated. NFC, wallet, Devnet and Anchor deployment are never marked green without runtime evidence. See [PHASE0.md](./PHASE0.md).

The repository contains the initial React Native shell, game module boundaries, SIGIL reducer baseline, and Anchor workspace scaffold.
